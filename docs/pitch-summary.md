# Pitch summary

Five sentences to paste into a Discord DM or an X message to a protocol team:

> I built an AI docs assistant for Uniswap that answers developer questions only from the official docs, links every answer to the exact section, and says "I don't know" instead of guessing.
> On 80 held-out test questions it declined all 23 questions the docs can't answer, and under 1% of the claims in its answers were unsupported by the docs, versus 5% for a typical RAG setup.
> Every number comes from a reproducible evaluation that is published with the code, including what didn't work.
> The same pipeline can be pointed at your protocol's docs with one config change, and it logs real user questions so you can see where your docs have gaps.
> You can try it live on Telegram at @Uniswapdocsqabot, and I'd be glad to run the same evaluation on your docs.
